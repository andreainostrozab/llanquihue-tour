## Autora
- **Nombre:** Andrea Inostroza Bascuñán
- **Carrera:** Analista Programador Computacional

## Descripción
Programa en Java que lee información de tours desde el archivo 'resources/tours.txt', crea objetos 'Tour', los almacena en un 'ArrayList', muestra todos los registros y filtra los tours de tipo Natural. 

## Estructura del proyecto
- 'src/model': clase 'Tour'
- 'src/data': clase 'GestorDatos'
- 'src/ui': clase 'Main'
- 'resources': archivo 'tours.txt'
- 'README.md': descripción del proyecto

## Cómo ejecutar la clase Main
1. Abrir el proyeto en IntelliJ IDEA
2. Verificar que 'resources/tours.txt' esté en la carpeta principal del proyecto.
3. Ejecuta el archivo 'Main.java' dentro del paquete 'ui
